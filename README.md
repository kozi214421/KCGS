# KCGS - STB Toolkit

This repository contains the **STB (Signal-based Technical Breakout) Toolkit** - a comprehensive 20-signal breakout trading system for TradingView.

## 🎯 Quick Overview

The STB Toolkit is an advanced trading system that combines:
- **20 technical signals** from multiple categories (technicals, volume, VWAP, relative strength, momentum)
- **Pine Script indicator** with visual buy/sell signals
- **Strategy for backtesting** with built-in risk management
- **Webhook integration** for real-time alerts
- **Optional institutional data enrichment** (short interest, options flow, dark pool data)

## 📂 What's Included

Navigate to the [`stb-toolkit/`](stb-toolkit/) directory for the complete system including:

- **Indicators:** TradingView Pine Script indicator
- **Strategies:** Backtesting strategy with risk management
- **Webhooks:** Python webhook handler for alert enrichment
- **Documentation:** Comprehensive setup, risk management, and validation guides
- **Examples:** Configuration templates and watchlists
